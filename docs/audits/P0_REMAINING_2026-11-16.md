## 집계 기준

- 기준은 통합된 main `b11dd2a`와 `codex/p0-round3-followup` 후속 수정을 합친 코드입니다. 작업 도중 #132·#135·#136이 병합되어 최신 main을 보존하며 다시 통합했습니다. 이 후속 브랜치의 수정까지 upstream main에 들어갔다는 뜻은 아닙니다.
- 원문 요약의 94건은 실제 ID 목록/우선순위 표와 맞지 않으므로 `94 - 수정 수`로 계산하지 않았습니다. 빨간 제목·P0 원문 ID를 현재 코드와 대조했습니다. 원문의 심각도 주장을 새로 인증한 것은 아닙니다.

- 실기는 복제/폐기 가능한 실험에서 수행하고, 버전·센서/펌웨어·로케일·DPI와 전후 화면/원시 응답을 기록해야 합니다. 실제 센서 출력이 필요한 절차는 장비·출력 범위가 정해진 뒤 수행합니다.
